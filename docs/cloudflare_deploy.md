# StarBank 家庭同步 · Cloudflare 部署教程（纯网页操作）

本教程不需要命令行，全程在 Cloudflare 网页控制台完成。部署完成后，你将得到一个
自己专属的家庭数据同步服务端，运行在 Cloudflare 免费套餐上。

需要的文件（都在本仓库 `cloudflare/` 目录）：

| 文件 | 用途 |
|---|---|
| `cloudflare/schema.sql` | D1 数据库表结构 |
| `cloudflare/worker.js` | Worker 服务端代码（单文件） |

前置条件：

- 一个 Cloudflare 账号（免费即可）
- 一个已接入 Cloudflare 的自己的域名（**必须**，`*.workers.dev` 在国内无法直连）

---

## 第 1 步：创建 D1 数据库

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧菜单找到 **存储和数据库（Storage & Databases）→ D1 SQL 数据库**
3. 点 **创建（Create Database）**
4. 名称填 `starbank-sync`（随意，记住即可），位置选默认，点创建

## 第 2 步：建表（执行 schema.sql）

1. 进入刚创建的 `starbank-sync` 数据库
2. 切到 **控制台（Console）** 标签页
3. 打开本仓库的 `cloudflare/schema.sql`，**整个文件内容**复制粘贴到输入框
4. 点 **执行（Execute）**
5. 成功后在「表（Tables）」标签里应能看到 6 张表：
   `families`、`users`、`tokens`、`records`、`counters`、`counter_ops`

## 第 3 步：创建 Worker 并粘贴代码

1. 左侧菜单 **Workers 和 Pages（Workers & Pages）**
2. 点 **创建（Create）→ 创建 Worker（Create Worker）**
3. 名称填 `starbank-sync`，点 **部署（Deploy）**（先部署默认的 Hello World）
4. 部署完成后点 **编辑代码（Edit code）** 进入在线编辑器
5. 删除编辑器里的全部默认代码，把本仓库 `cloudflare/worker.js` 的**全部内容**粘贴进去
6. 点右上角 **部署（Deploy）**

## 第 4 步：绑定 D1 数据库

1. 回到该 Worker 的详情页，进入 **设置（Settings）→ 绑定（Bindings）**
2. 点 **添加（Add）→ D1 数据库（D1 Database）**
3. **变量名称必须填 `DB`**（大写，一字不差）
4. 数据库选择第 1 步创建的 `starbank-sync`
5. 保存（保存后 Worker 会自动重新部署）

## 第 5 步：设置管理员令牌 ADMIN_TOKEN

1. 还是在 **设置（Settings）→ 变量和机密（Variables and Secrets）**
2. 点 **添加（Add）**，类型选 **机密（Secret）**
3. 变量名称填 `ADMIN_TOKEN`
4. 值填一个**你自己想的长随机密码**（建议 20 位以上字母数字，比如密码管理器生成），
   这是管理后台的钥匙，**记到安全的地方**
5. 保存并部署

## 第 6 步：绑定自定义域名（国内直连的关键）

1. Worker 详情页 → **设置（Settings）→ 域和路由（Domains & Routes）**
2. 点 **添加（Add）→ 自定义域（Custom Domain）**
3. 填一个你域名下的子域名，例如 `sync.你的域名.com`
4. 点添加，Cloudflare 会自动配置 DNS 和证书，等待状态变为「有效」

> 为什么必须这一步：`xxx.workers.dev` 域名在国内基本被墙，绑定你自己的域名后
> 手机才能直接连接。

## 第 7 步：验证部署

1. 手机或电脑浏览器打开 `https://sync.你的域名.com/`
   - 看到 `{"ok":true,"service":"starbank-family-sync"}` 即部署成功
2. 打开 `https://sync.你的域名.com/admin`
   - 输入你在第 5 步设置的 ADMIN_TOKEN，点保存，再点「刷新数据」
   - 能看到（空的）家庭列表即管理页正常

如果第 1 步就报错：
- **错误 1101 / "服务器内部错误"**：多半是 D1 没绑定或变量名不是 `DB`，回到第 4 步检查
- **"未配置 ADMIN_TOKEN"（仅 /admin 页）**：第 5 步没做或没部署生效

**同步过程中出现 HTTP 503：**
1. 看错误提示里的 **Cloudflare 错误码**（App 会显示）：
   - `1102`（超出资源限额）：免费版单请求 CPU 限额被大批量数据撑爆。App 已内置
     小批量+自动重试，多点几次「立即同步」即可分批传完；数据不会丢也不会重复
     （所有接口幂等）。
   - `1101`（Worker 抛异常）：多半是 D1 未绑定/表结构不对，检查第 2、4 步
   - 无错误码：检查域名的 **安全性 → Bot Fight Mode / WAF 自定义规则 /
     Under Attack 模式** 是否拦截了 App 请求，为该子域放行
2. 浏览器访问 `https://sync.你的域名.com/` 确认服务本身正常
3. 国内网络抖动也可能偶发 503，App 会自动重试 3 次

## 第 8 步：在 App 中启用

**爸爸的手机（主号）：**
1. StarBank → 设置 → 家庭同步（需家长模式）
2. 端点填 `https://sync.你的域名.com`，点「连接服务端」
3. 选「注册一个」，填用户名+密码（≥6 位）→ **注册并启用同步**
4. 注册即自动创建家庭并上传本地数据

**创建子号：**
1. 主号手机 → 家庭同步页 → 家庭成员 → **添加子号**
2. 设置子号用户名和初始密码，告诉另一半

**妈妈的手机（子号）：**
1. 同样进入 设置 → 家庭同步，填同一个端点，点「连接服务端」
2. 用子号账号密码**登录**
3. 如果这台手机之前单机用过，会弹出二选一：
   - **以云端为准（推荐）**：本地核心数据被云端替换，替换前自动保存本地快照文件
   - **合并上传**：两边数据都保留，但同一个孩子会变成两个宝宝档案，需手动删一个

之后两台手机就会自动同步：改动后几秒内推送，前台每 3 分钟拉取，
回到前台立即拉取，也可以在家庭同步页手动「立即同步」。

## 同步了什么 / 没同步什么

**同步**：宝宝档案、星星数、存钱罐/零花钱余额、星星日志、快捷行为、商店商品、
成长记录、里程碑、便便记录、AI 聊天、故事会话、测验题库与配置、百科题库与配置、
新年故事、自定义谜语、AI/TTS 配置（含 API Key，存在你自己的 D1 里）、常用设置。

**不同步**：照片视频等媒体文件（继续走亲宝宝的 WebDAV/阿里云盘通道）、音乐歌单、
AI 生成的图片、百科解释缓存。WebDAV 备份功能保留不变，作为全量备份手段。

**并发安全**：星星/余额采用「操作累加」——爸爸 +5、妈妈 +3 同时操作，最终就是 +8，
谁都不会丢。其余数据按「新改动覆盖旧改动」合并（两台设备同时改同一个宝宝的名字，
以后保存的为准）。

## 忘记密码怎么办

- **子号忘了**：主号手机 → 家庭同步 → 家庭成员 → 该子号右侧「重置密码」
- **主号忘了**：浏览器打开 `https://sync.你的域名.com/admin`，用 ADMIN_TOKEN 登录，
  在「重置用户密码」里输入主号用户名和新密码

## 免费额度够用吗

| 资源 | 免费额度/天 | 一家三台设备的典型用量/天 |
|---|---|---|
| Worker 请求 | 100,000 次 | < 2,000 次 |
| D1 行读取 | 500 万行 | < 5 万行 |
| D1 行写入 | 10 万行 | < 5,000 行 |
| D1 存储 | 5 GB | 通常 < 50 MB |

结论：随便用，距离免费上限差两个数量级。

## 后续更新服务端代码

仓库里的 `cloudflare/worker.js` 有更新时：Worker 详情页 → 编辑代码 → 全选替换为
新版本 → 部署。数据都在 D1 里，更新代码不影响数据。

**2026-07-26 版本升级注意**：如果你在此日期前已部署过，除了替换 worker.js，
还需在 D1 控制台执行一次迁移（新部署无需）：

```sql
ALTER TABLE counter_ops ADD COLUMN applied INTEGER NOT NULL DEFAULT 0;
UPDATE counter_ops SET applied = 1;
```

## 已知限制（家庭场景可接受）

- 数据合并使用设备本机时间做「新者胜」判断，请保持两台手机时间正常（自动网络时间即可）
- 两台设备在**互相未同步期间**都触发存钱罐利息结算的极端情况下，利息可能重复计一次
- 令牌长期有效；手机丢失时用管理页「吊销用户所有登录」即可踢下线
